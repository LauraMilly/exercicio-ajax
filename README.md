# 📌 Exercício AJAX com GitHub API

Este projeto é um exercício prático do módulo FrontEnd M23, que consiste em preencher dinamicamente os dados de um perfil do GitHub usando **AJAX** com a **Fetch API**.

## 🚀 Funcionalidades

- Consulta a API pública do GitHub.
- Atualiza foto de perfil, nome, username, número de repositórios, seguidores e seguindo.
- Link direto para o perfil do GitHub.
